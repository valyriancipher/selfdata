📌 Project Overview
This repository contains the source code for a personal webpage created using HTML and CSS for the Class 10 Half-Yearly examination project.
The webpage introduces my background, interests, and future goals while implementing core front-end styling and structure.

---

🚀 Webpage Features & Content
- Introduction & About Me: A brief overview of personal interests and hobbies.
- Future Goals: A structured list highlighting upcoming academic and personal goals.
- Visuals & Media: Styled profile image and decorative elements.
- Navigation & Links: External links to relevant profiles and projects.
- Lists: Ordered and unordered lists organizing skills, hobbies, and goals.

---

💻 Technical Concepts Used

1. HTML5 Structure
- Semantic tags: `<header>`, `<main>`, `<section>`, `<footer>`
- Content formatting: `<h1>` to `<h3>`, `<p>`, `<ul>`, `<ol>`, `<li>`
- Media & navigation: `<img>`, `<a>` (with attributes like `src`, `alt`, and `href`)

2. CSS Styling
- Typography & Colors: Custom fonts, text alignment, and color palettes.
- Box Model: Margins, padding, borders, and border-radius.
- Layout & Spacing: Centering containers, list styling, and link hover states.

---

📁 File Structure
- `index.html` — Main HTML document containing the structure and content.
- `style.css` — Stylesheet containing all CSS styling rules.
- `assets/` — Folder containing relevant project images.
